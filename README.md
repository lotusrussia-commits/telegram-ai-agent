# Telegram AI Agent

AI-агент на Python, который умеет самостоятельно выбирать и использовать инструменты для выполнения задач.

Агент работает через LLM и доступен как в Telegram, так и через командную строку.

## Возможности

Агент умеет:

* искать информацию в интернете через DuckDuckGo;
* получать текущую погоду в любом городе;
* получать курс криптовалют;
* получать курсы обычных валют;
* читать текстовые файлы;
* создавать и записывать текстовые файлы;
* выполнять математические расчёты;
* сохранять историю диалога в `memory.json`;
* записывать действия агента в `agent.log`;
* выполнять математические расчёты через отдельный инструмент.

## Как работает агент

Пользователь отправляет запрос.

LLM анализирует запрос и при необходимости выбирает подходящий инструмент.

Например, пользователь может спросить:

```
Какая сейчас погода в Варшаве?
```

Агент:

```
1. Определяет, что нужна информация о погоде.
2. Вызывает инструмент get_weather.
3. Получает данные Open-Meteo.
4. Формирует ответ пользователю.
```

Если инструмент не нужен, агент отвечает напрямую.

История последних сообщений сохраняется в `memory.json`, поэтому агент может учитывать предыдущие сообщения диалога.

## Инструменты

### DuckDuckGo

Поиск информации в интернете.

### Погода

Используется Open-Meteo для определения города и получения текущих погодных данных.

### Криптовалюта

Используется CoinGecko для получения текущей стоимости поддерживаемых криптовалют.

### Валюты

Используется Frankfurter API для получения курсов обычных валют.

### Файлы

Агент может создавать, записывать и читать текстовые файлы.

Файлы сохраняются в:

```
data/agent_files/
```

### Калькулятор

Агент умеет выполнять математические расчёты с помощью отдельного инструмента.

## Память

История диалога сохраняется в:

```
memory.json
```

Агент использует сохранённую историю при обработке следующих запросов.

## Логирование

Действия агента записываются в:

```
agent.log
```

В логе можно увидеть запрос пользователя, выбранный инструмент, его аргументы, результат выполнения и завершение запроса.

## Telegram

Telegram-бот реализован с использованием `aiogram`.

После запуска можно отправить боту:

```
/start
```

Примеры запросов:

```
Какая сейчас погода в Варшаве?

Сколько будет 125 * 37 + 850?

Какой сейчас курс EUR к USD?

Сколько стоит BTC?

Найди официальный сайт Python.
```

Также можно попросить агента создать файл и затем прочитать его содержимое.

## Локальный запуск

В проекте есть два варианта запуска.

### Telegram-бот

```
python -m app.bot
```

### Локальный AI-агент

```
python run.py
```

Для выхода из локального режима:

```
exit
```

## Установка

Создать виртуальное окружение:

```
python3 -m venv .venv
```

Активировать его:

```
source .venv/bin/activate
```

Установить зависимости:

```
pip install -r requirements.txt
```

## Настройка

Создать файл `.env` и указать:

```
TELEGRAM_BOT_TOKEN=your_telegram_bot_token
PROXYAPI_KEY=your_proxyapi_key
PROXYAPI_BASE_URL=https://api.proxyapi.ru/v1
LLM_MODEL=openai/gpt-5-mini
```

Секретные ключи не должны добавляться в Git.
